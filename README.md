# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62005

## 风箱压力复测

在调音记录页底部提供风箱压力复测模块：

- 每次维护登记各测点的**静压**与**演奏中最低风压**（Pa）。
- 同一音栓内**响应差（各测点压降最大差异）> 4 Pa** 或**压降 > 6 Pa** 时，整组转为「待复测」，原调音结论保留展示且不被修改。
- 复测合格只恢复对应音栓组；不合格或未复测的组继续锁定。待复测组的合格维护登记不会自动解锁，必须走复测。
- 各场馆状态分别保存到浏览器 localStorage，切换场馆互不影响，刷新后仍可读；无后端、无新增依赖。

代码按三层拆分在 `src/windPressure/`：

| 文件 | 职责 |
| --- | --- |
| `pressureLogic.ts` | 风压判定（压降 / 响应差阈值）、维护登记与复测的纯状态流转 |
| `pressureStore.ts` | React 状态 + localStorage 按场馆持久化与读回校验、演示种子数据 |
| `WindPressurePanel.tsx` | 页面展示：场馆切换、音栓状态卡片、登记表单、实时判定预览、维护/复测时间线 |
