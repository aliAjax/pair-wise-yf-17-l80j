# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 风箱压力复测

在调音记录页内新增「风箱压力复测」：

- 每次维护按音栓内多个测点登记**静压**与**演奏中最低风压**（Pa）。
- 判定规则：单点压降 = 静压 − 最低风压；同栓**响应差**（各测点压降跨度）超过 **4Pa**，或任一测点**压降**超过 **6Pa**，整组音栓转为「待复测」并锁定，**原调音结论保留不动**。
- 待复测组只能登记复测：复测合格仅恢复该音栓，其他未复测组仍锁定；复测不合格继续锁定。
- 各场馆的音栓组状态分别保存（localStorage，无后端、无新增依赖），切换场馆互不影响，刷新页面仍可读。

代码按职责拆分为三个业务文件：

| 文件 | 职责 |
| --- | --- |
| `src/wind/pressure.ts` | 风压判定：压降、响应差、超限阈值、音栓组状态流转（纯函数） |
| `src/wind/storage.ts` | 状态存储：场馆分组、localStorage 持久化、`useWindStore` |
| `src/wind/WindPressurePanel.tsx` | 页面展示：场馆切换、音栓卡片、维护/复测表单与锁定提示 |
